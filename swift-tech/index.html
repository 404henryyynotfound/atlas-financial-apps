from the edge.

  1. S

06 / Developer docs

Built to be inspected,
extended, and automated.

The Developer edition is a sketch of a better debugging surface: remote sessions, extension hooks, and an automation API that stays on your machine. The snippet below illustrates the intended shape, not a shipped SDK.

Debug a tab

// proposed API surface — not shipped yet
const session = await swift.debug.attach({
  target: "tab-1",
  remote: true
});

session.on("Runtime.consoleAPICalled", (event) => {
  console.log(event.args.map((arg) => arg.value));
});

await session.send("Runtime.enable");

Register an extension hook

// planned extension surface
swift.extensions.register({
  id: "local-notes-inspector",
  permission: "activeTab",
  onPageReady(tab) {
    return tab.readDOM("#article");
  }
});
